# VSRead · 青菜阅读 0.1.9 手动验收清单

这份清单用于安装 VSIX 后验证 CodeBuddy / VS Code。自动化测试中的 VS Code API 和浏览器 Host 消息均为模拟，实际 IDE 中仍需确认冷启动、资源加载和进度恢复。

## 1. 安装准备

- [ ] 记录 IDE 名称、IDE 版本和操作系统。
- [ ] 从 GitHub Release 下载 `vsread-0.1.9.vsix`，在扩展页面的 `…` 菜单选择“从 VSIX 安装…”。已安装旧版本时直接覆盖安装，无需卸载。
- [ ] 按提示重载 IDE，在扩展详情中确认名称为“VSRead · 青菜阅读”、版本为 `0.1.9`；同一 IDE 和用户配置文件中的原有书架与进度仍保留。
- [ ] 扩展详情“功能 → 运行时状态”中，不再出现容器 ID 格式错误或“视图容器不存在”消息。
- [ ] 关闭所有 VSRead 阅读标签后完全退出 IDE；重新启动，仅点击活动栏书本图标，侧栏应显示操作项，不出现“没有可提供视图数据的已注册数据提供程序”。
- [ ] 再次完全退出并启动 IDE，直接通过命令面板执行“VSRead: 打开阅读器”，无需先点击侧栏也能打开。
- [ ] 活动栏能看到 **VSRead · 青菜阅读** 书本图标；切换 IDE 浅色 / 深色主题时图标仍清晰可见。侧栏提供“打开阅读器”“导入本地电子书”“在线书源”和“检查更新”。
- [ ] 点击侧栏“打开阅读器”，正文界面在编辑器标签页打开；侧栏标题栏的书本按钮也能打开同一个阅读器。
- [ ] 点击侧栏“导入本地电子书”或标题栏的 `+`，能弹出本地文件选择；取消选择后侧栏与阅读器仍可操作。
- [ ] `Ctrl+Shift+P` → **VSRead: 打开阅读器**，能看到空书架或已有书架，没有空白页面。
- [ ] 准备 UTF-8 TXT、GBK / GB18030 TXT、带图片和 CSS 的无 DRM EPUB、文字型 PDF；有条件再准备扫描型 PDF 和较大的 TXT。

项目开发环境可执行 `node test/fixtures.mjs` 生成 `.test-data/fixtures/demo.txt`、`demo.epub`、`demo.pdf`。这些是自制测试材料，不会随插件自动进入书架。

如果没有看到活动栏图标，先执行 **Developer: Reload Window**（开发人员：重新加载窗口），检查活动栏 `…` 溢出菜单，或右键活动栏并勾选 **VSRead**。若活动栏本身被隐藏，先在 IDE 的外观设置中显示活动栏。

## 2. 导入与书架

- [ ] 点击“导入书籍”，分别导入 TXT、EPUB、PDF，能打开正文；也可多选批量导入。
- [ ] 取消文件选择后，阅读器仍可操作。
- [ ] 回到“我的书架”，能看到三种格式的条目；点击可切换阅读。
- [ ] 添加一本在线小说后返回“我的书架”，本地书籍和在线小说出现在同一列表，均可直接继续阅读。
- [ ] 分别打开本地书与在线小说，点击顶部“我的书架”均返回同一书架，各自进度保持独立。
- [ ] 重复导入同一个文件，不出现重复书籍。
- [ ] EPUB 打开后书架中的书名、作者及可用封面得到更新。
- [ ] 移动或重命名最初导入的原文件，书架中已有副本仍可打开。
- [ ] 书架中的阅读进度显示两位小数，例如“已读 5.00%”；阅读正文时底部状态栏采用相同格式。

## 3. TXT

- [ ] UTF-8 和 GBK / GB18030 文件显示正常，无明显乱码。
- [ ] 自动识别不正确时可在工具栏手选编码；重新解析后正文正常。此操作会重置这本书的旧位置。
- [ ] “第一章”“第十二章”“Chapter 1”等常见标题进入目录；点击目录能跳转。
- [ ] 没有标题的 TXT 仍能显示“正文”，长内容有分块条目。
- [ ] 滚动、上一页、下一页可用；到当前块底部后点击下一页能进入下一块。
- [ ] 调整字号、行距、字体，正文更新且仍停留在相近文字位置。
- [ ] 字号既可用滑块调节，也可直接输入 12–40 范围内的数字；输入后正文大小与显示值一致。
- [ ] 较大的 TXT 导入时显示进度提示，打开后只渲染当前块，IDE 仍能响应编辑和切换标签。

## 4. EPUB

- [ ] 正文在阅读区正常显示，目录可展开或筛选并跳转。
- [ ] 内部图片可见，书籍内嵌 CSS 排版生效。
- [ ] “阅读设置”中切换章节内滚动与分页，两种模式都能阅读和翻页。
- [ ] 浅色、深色、跟随 IDE、自定义背景与文字颜色，以及字号和行距调整生效。
- [ ] 前后翻页及多次目录跳转后，没有空白页、加载卡死或红色错误提示。
- [ ] 使用项目 `demo.epub` 时能看到“星海插图”，章节标题带绿色样式；示例包含的测试脚本不会运行。

## 5. PDF

- [ ] 首页渲染正常，没有 Worker 加载失败、401 或空白画布。
- [ ] 上一页、下一页可用；有 PDF 内置目录时能跳转，无目录时能按页码选择。
- [ ] 缩放可用；高倍率时能够滚动查看页面。
- [ ] 文字型 PDF 可用鼠标选择文字；搜索已知词语，匹配页摘要出现且点击能跳转。
- [ ] 搜索不存在的词语能显示无结果，关闭结果面板后可继续阅读。
- [ ] 扫描型 PDF 可正常显示和翻页；搜索无结果属于当前 OCR 未实现的正常行为。
- [ ] 如有中文 PDF，检查中文字体、标点、图像是否正确。
- [ ] 分别记录首次打开、返回书架后再次打开同一 PDF，以及相邻页面前后翻页的等待时间；用较大 PDF 重复检查，记录文件大小和页面数量。
- [ ] 同一阅读器标签页内，返回书架后立即重开同一 PDF，正文、文字层及原有位置正确；已访问页面前后切换也能正常显示。
- [ ] 返回书架后等待约一分钟、切换多本 PDF，或关闭 VSRead 标签后重新打开，仍能正常阅读与恢复位置；短时缓存可能已释放，再次读取属于正常行为。
- [ ] 对复杂扫描件单独记录首次打开与翻页耗时，不以小型文字 PDF 的速度作为所有文件的预期。
- [ ] 切换浅色、深色或自定义背景后，界面与 PDF 页面周围的阅读区更新；原稿页面纸色与内容配色保持原样。

## 6. 进度与重启（核心验收）

以下步骤对 **TXT、EPUB、PDF 各做一次**：

1. 阅读到明显不同于开头的位置：TXT 进入后续章节并滚动；EPUB 进入后续章节并翻页；PDF 进入后续页面并滚动。
2. 记住当前可见的一句话，或 PDF 页码及页内位置；等待底部显示“进度已保存”。
3. 返回书架再打开该书，应恢复到相同或相近文字位置。
4. 关闭 VSRead 标签页，再用命令重新打开，应恢复最后一本书及位置。
5. 完全退出 IDE，再重新启动并打开 VSRead，应恢复最后一本书及位置。
6. 切换另外两本书，确认各自进度彼此独立。

- [ ] TXT 章节及字符位置恢复。
- [ ] EPUB CFI 位置恢复，未跳回第一章。
- [ ] PDF 页码及页内滚动位置恢复。
- [ ] 已选主题、字号、行距、字体或 PDF 缩放在重新打开后保留。
- [ ] 右上角能直接找到“阅读设置”；选择自定义背景和文字颜色，返回书架、切换书籍及重启 IDE 后仍保留。
- [ ] 打开阅读设置后，点击面板外的空白、TXT / PDF 阅读区或 EPUB iframe 正文，面板关闭；按 `Esc` 也能关闭。
- [ ] 在设置面板内拖动字号 / 行距滑块、输入数字、选择主题或调色时，面板保持打开且操作正常。
- [ ] 将外观切回“跟随 IDE”，再切换 IDE 的浅色 / 深色主题，阅读器背景与 TXT / EPUB 正文配色随之更新。
- [ ] 打开普通代码编辑器、切换标签、调整 IDE 面板宽度后，阅读器仍可操作。

## 7. 删除与异常

- [ ] 点击书架的移除按钮，取消确认后书籍仍存在。
- [ ] 确认移除后该书从书架消失，最初导入的原文件仍保留。
- [ ] 空 TXT 或超过当前体积上限的文件有可理解的错误提示，其他书仍可正常打开。
- [ ] 加密 PDF 或损坏文件有错误提示，不影响返回书架后打开正常书籍。

## 8. 在线书源与版本检查

- [ ] 顶部书源下拉框包含 8 个内置选项：酷我小说、零零小说、爱下书吧、下书看、经致文学 · 公开章节、Project Gutenberg · 中文、Project Gutenberg、Standard Ebooks。
- [ ] 在顶部下拉框选择酷我小说搜索“系统”、零零小说与爱下书吧搜索“诡秘之主”、下书看搜索“狐妖”，分别验证目录与正文，抽查长篇中后段内容可读。
- [ ] 打开“在线书源”，无需导入即可在顶部下拉框选择内置来源；选择经致文学搜索“三国”，加入书架，目录只列公开章节，正文可读。
- [ ] 选择 Gutenberg 中文搜索 `論語`，选择多语言目录搜索 `Pride and Prejudice`，选择 Standard Ebooks 搜索 `the raven` 并打开 Poe 的 `Poetry`，分别验证搜索及整书正文。
- [ ] 点击“新增书源”，粘贴 `examples/sources/gutenberg.json` 内容导入；也可切换配置链接导入，自定义来源仍出现在搜索下拉框。
- [ ] 书源可以停用、重新启用和移除；不支持的规则明确显示导入原因。
- [ ] 阅读后续章节并滚动，返回“我的书架”再打开在线小说，章节及滚动位置恢复。
- [ ] 缓存当前章及后续章节，断网后仍可打开这些内容；未缓存章节提示网络或缓存状态。
- [ ] 点击“缓存全本”，进度显示已缓存 / 总章节数，可继续正常阅读；已经缓存的章节不重复下载。
- [ ] 缓存过程中取消，已完成章节保留；点击“继续缓存”仅补齐未完成内容。
- [ ] 关闭阅读器标签后重新打开，后台任务进度可见，阅读章节及滚动位置不被下载进度覆盖。
- [ ] 退出 IDE 后重新启动，已下载章节保留，再开始缓存可继续；达到容量上限或站点拒绝时暂停并显示原因。
- [ ] 清理缓存或移除在线书籍后，后台任务不再继续下载或重新创建已删除缓存。
- [ ] 切换 IDE 标签或重载保留的阅读器，在线页面及当前书籍恢复；目录刷新后位置与缓存对应正确章节。
- [ ] “检查更新”显示新版本、已是最新或无法确认的准确状态；仓库没有 Release 时不会误报最新。
- [ ] 有新版本时点击“一键更新”，原生通知显示下载进度；下载阶段取消不会安装，仍可再次更新。
- [ ] 更新期间关闭并重新打开更新面板，不会重复下载；安装完成后提供“重载窗口”，重载后版本与书架数据正确。
- [ ] 下载或安装失败后可重试，也可通过“查看发布页”手动安装；失败或取消不会显示安装成功。
- [ ] 配置与清除更新令牌使用原生输入；页面与日志不会显示令牌内容。

## 9. 键盘与专注阅读

- [ ] TXT / EPUB 滚动模式、PDF 与在线章节中，`↑` / `↓` 能上下滚动，抵达边界后停住；输入框、选择框内不抢占方向键。
- [ ] 在线章节滚到末尾，按 `→` 或点击“下一章”，新章节从章首开始；连续切换多章、向左返回也正常。
- [ ] EPUB 滚动模式从章尾前往下一章时回到章首；重新打开书籍仍恢复保存的 CFI。
- [ ] 点击“专注阅读”或按 `Ctrl+Alt+H`（macOS 为 `Cmd+Option+H`），品牌、书名、目录、工具栏和底部状态收起，IDE 标签改为普通文件图标和 `notes.txt`，正文与阅读位置保留。
- [ ] 按 `Esc` 或再次按上述快捷键恢复；鼠标悬停右上角也能找到恢复按钮。EPUB iframe 正文聚焦时同样可用。
- [ ] 在 IDE 中通过命令面板执行“VSRead: 切换专注阅读”，与页面按钮切换一致；回到代码编辑器后此快捷键不再由 VSRead 接管。

## 10. 书源诊断日志

- [ ] 执行 **VSRead: 打开诊断日志**，或点击侧栏日志入口，能在 IDE 中预览本地 `vsread.log` 文件。
- [ ] 在线搜索、目录或正文读取失败时，错误提示提供“查看日志”按钮；点击后能打开诊断日志。
- [ ] 复现一次书源请求失败，日志包含对应书源、操作阶段、脱敏后的域名 / 路径、耗时和错误码；HTTP 错误包含状态码，网络错误能看出 DNS、连接、响应或下载阶段。
- [ ] 用容易识别的测试关键词搜索并检查日志，确认没有记录搜索关键词、章节正文或访问令牌等凭据。
- [ ] 断网后尝试搜索，操作最终显示明确错误并结束加载；恢复网络后可重新搜索和阅读，本地书籍仍可正常打开。

遇到空白、401、Worker 或 CSP 报错，可打开 IDE 的开发者工具，复制相关错误文本并附上截图。反馈不需要提供整本私人书籍；若能用自制短文件复现，附上该文件即可。
