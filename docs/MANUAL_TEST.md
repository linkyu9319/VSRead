# VSRead 0.1.2 手动验收清单

这份清单用于实际安装 VSIX 后验证 CodeBuddy / VS Code。独立浏览器中的测试通过不等于 IDE Webview 沙箱已通过；此前 CodeBuddy 自动化验证曾遇到书籍本地资源 401，当前已改为 Extension Host 分块传输书籍字节，仍需重点手测资源加载和进度恢复。

本版已通过 TypeScript、构建、底层测试与独立浏览器回归，覆盖颜色偏好、进度、PDF 按需读取及同一 Webview 内的文档复用。独立浏览器测试不能替代真实 IDE 中的使用体验；当前交付不运行 CodeBuddy 自动化，以下勾选项需在实际 IDE 中确认。

## 1. 安装准备

- [ ] 记录 IDE 名称、IDE 版本和操作系统。
- [ ] 在扩展页面的 `…` 菜单选择“从 VSIX 安装…”，选择 `vsread-0.1.2.vsix`。已安装 0.1.0 / 0.1.1 时直接覆盖安装，无需卸载。
- [ ] 按提示重载 IDE，在扩展详情中确认版本为 `0.1.2`；同一 IDE 和用户配置文件中的原有书架与进度仍保留。
- [ ] 活动栏能看到 **VSRead 书本图标**；点击后打开 VSRead 侧栏，其中有“打开阅读器”和“导入本地电子书”两项。
- [ ] 点击侧栏“打开阅读器”，正文界面在编辑器标签页打开；侧栏标题栏的书本按钮也能打开同一个阅读器。
- [ ] 点击侧栏“导入本地电子书”或标题栏的 `+`，能弹出本地文件选择；取消选择后侧栏与阅读器仍可操作。
- [ ] `Ctrl+Shift+P` → **VSRead: 打开阅读器**，能看到空书架或已有书架，没有空白页面。
- [ ] 准备 UTF-8 TXT、GBK / GB18030 TXT、带图片和 CSS 的无 DRM EPUB、文字型 PDF；有条件再准备扫描型 PDF 和较大的 TXT。

项目开发环境可执行 `node test/fixtures.mjs` 生成 `.test-data/fixtures/demo.txt`、`demo.epub`、`demo.pdf`。这些是自制测试材料，不会随插件自动进入书架。

如果没有看到活动栏图标，先执行 **Developer: Reload Window**（开发人员：重新加载窗口），检查活动栏 `…` 溢出菜单，或右键活动栏并勾选 **VSRead**。若活动栏本身被隐藏，先在 IDE 的外观设置中显示活动栏。

## 2. 导入与书架

- [ ] 点击“导入书籍”，分别导入 TXT、EPUB、PDF，能打开正文；也可多选批量导入。
- [ ] 取消文件选择后，阅读器仍可操作。
- [ ] 回到“我的书架”，能看到三种格式的条目；点击可切换阅读。
- [ ] 重复导入同一个文件，不出现重复书籍。
- [ ] EPUB 打开后书架中的书名、作者及可用封面得到更新。
- [ ] 移动或重命名最初导入的原文件，书架中已有副本仍可打开。
- [ ] 书架中的阅读进度显示两位小数，例如“已读 5.00%”；阅读正文时底部状态栏采用相同格式。

## 3. TXT

- [ ] UTF-8 和 GBK / GB18030 文件显示正常，无明显乱码。
- [ ] 自动识别不正确时可在工具栏手选编码；重新解析后正文正常。此操作会重置这本书的旧位置。
- [ ] “第一章”“第十二章”“Chapter 1”等常见标题进入目录；点击目录能跳转。
- [ ] 没有标题的 TXT 仍能显示“正文”，长内容有分块条目。
- [ ] 滚动、上一页、下一页可用；到当前块底部后点击下一页能进入下一块。
- [ ] 调整字号、行距、字体，正文更新且仍停留在相近文字位置。
- [ ] 字号既可用滑块调节，也可直接输入 12–40 范围内的数字；输入后正文大小与显示值一致。
- [ ] 较大的 TXT 导入时显示进度提示，打开后只渲染当前块，IDE 仍能响应编辑和切换标签。

## 4. EPUB

- [ ] 正文在阅读区正常显示，目录可展开或筛选并跳转。
- [ ] 内部图片可见，书籍内嵌 CSS 排版生效。
- [ ] “阅读设置”中切换章节内滚动与分页，两种模式都能阅读和翻页。
- [ ] 浅色、深色、跟随 IDE、自定义背景与文字颜色，以及字号和行距调整生效。
- [ ] 前后翻页及多次目录跳转后，没有空白页、加载卡死或红色错误提示。
- [ ] 使用项目 `demo.epub` 时能看到“星海插图”，章节标题带绿色样式；示例包含的测试脚本不会运行。

## 5. PDF

- [ ] 首页渲染正常，没有 Worker 加载失败、401 或空白画布。
- [ ] 上一页、下一页可用；有 PDF 内置目录时能跳转，无目录时能按页码选择。
- [ ] 缩放可用；高倍率时能够滚动查看页面。
- [ ] 文字型 PDF 可用鼠标选择文字；搜索已知词语，匹配页摘要出现且点击能跳转。
- [ ] 搜索不存在的词语能显示无结果，关闭结果面板后可继续阅读。
- [ ] 扫描型 PDF 可正常显示和翻页；搜索无结果属于当前 OCR 未实现的正常行为。
- [ ] 如有中文 PDF，检查中文字体、标点、图像是否正确。
- [ ] 分别记录首次打开、返回书架后再次打开同一 PDF，以及相邻页面前后翻页的等待时间；用较大 PDF 重复检查，记录文件大小和页面数量。
- [ ] 同一阅读器标签页内，返回书架后立即重开同一 PDF，正文、文字层及原有位置正确；已访问页面前后切换也能正常显示。
- [ ] 返回书架后等待约一分钟、切换多本 PDF，或关闭 VSRead 标签后重新打开，仍能正常阅读与恢复位置；短时缓存可能已释放，再次读取属于正常行为。
- [ ] 对复杂扫描件单独记录首次打开与翻页耗时，不以小型文字 PDF 的速度作为所有文件的预期。
- [ ] 切换浅色、深色或自定义背景后，界面与 PDF 页面周围的阅读区更新；原稿页面纸色与内容配色保持原样。

## 6. 进度与重启（核心验收）

以下步骤对 **TXT、EPUB、PDF 各做一次**：

1. 阅读到明显不同于开头的位置：TXT 进入后续章节并滚动；EPUB 进入后续章节并翻页；PDF 进入后续页面并滚动。
2. 记住当前可见的一句话，或 PDF 页码及页内位置；等待底部显示“进度已保存”。
3. 返回书架再打开该书，应恢复到相同或相近文字位置。
4. 关闭 VSRead 标签页，再用命令重新打开，应恢复最后一本书及位置。
5. 完全退出 IDE，再重新启动并打开 VSRead，应恢复最后一本书及位置。
6. 切换另外两本书，确认各自进度彼此独立。

- [ ] TXT 章节及字符位置恢复。
- [ ] EPUB CFI 位置恢复，未跳回第一章。
- [ ] PDF 页码及页内滚动位置恢复。
- [ ] 已选主题、字号、行距、字体或 PDF 缩放在重新打开后保留。
- [ ] 右上角能直接找到“阅读设置”；选择自定义背景和文字颜色，返回书架、切换书籍及重启 IDE 后仍保留。
- [ ] 打开阅读设置后，点击面板外的空白、TXT / PDF 阅读区或 EPUB iframe 正文，面板关闭；按 `Esc` 也能关闭。
- [ ] 在设置面板内拖动字号 / 行距滑块、输入数字、选择主题或调色时，面板保持打开且操作正常。
- [ ] 将外观切回“跟随 IDE”，再切换 IDE 的浅色 / 深色主题，阅读器背景与 TXT / EPUB 正文配色随之更新。
- [ ] 打开普通代码编辑器、切换标签、调整 IDE 面板宽度后，阅读器仍可操作。

## 7. 删除与异常

- [ ] 点击书架的移除按钮，取消确认后书籍仍存在。
- [ ] 确认移除后该书从书架消失，最初导入的原文件仍保留。
- [ ] 空 TXT 或超过当前体积上限的文件有可理解的错误提示，其他书仍可正常打开。
- [ ] 加密 PDF 或损坏文件有错误提示，不影响返回书架后打开正常书籍。
