# 🥬 VSRead | 青菜阅读

青菜阅读（VSRead）是面向 CodeBuddy IDE 和 Visual Studio Code 的电子书阅读扩展，支持本地 EPUB、TXT、PDF，以及可配置的在线书源。书库、阅读进度、偏好和章节缓存保存在本机。

![青菜阅读：IDE 侧栏入口与本地、在线书籍统一书架](docs/images/bookshelf.png)

## 功能

| 内容 | 支持能力 |
| --- | --- |
| EPUB | 目录、图片与样式、元数据、分页与滚动阅读、书内全文搜索、CFI 位置恢复 |
| TXT | UTF-8、GBK / GB18030、UTF-16 编码识别，章节识别、分块阅读与宿主全文搜索 |
| PDF | 按需读取、缩放与翻页、深色反色/暖纸护眼滤镜、目录、文字选择与搜索、页码恢复 |
| 在线书源 | 内置来源、自定义 JSON 导入、单源及聚合搜索、一键换源、批量检查更新、正文净化、预加载下一章、全本缓存与导出 TXT |

- 本地与在线书籍统一书架，支持搜索筛选、分类排序、置顶与阅读进度自动保存恢复。
- 跟随 IDE、浅色、深色及自定义配色。
- TXT / EPUB 与在线正文支持字号、行距、正文最大宽度、段间距与字体设置；PDF 支持缩放与深色反色/暖纸滤镜。
- GitHub 正式版本检查与一键更新。
- 一键专注阅读，隐藏名称与工具栏，使用快捷键恢复。

## 安装与使用

1. 从 [GitHub Releases](https://github.com/linkyu9319/VSRead/releases/latest) 下载最新版本的 `.vsix` 安装包。
2. 在 IDE 扩展面板选择 **从 VSIX 安装…**，安装后重载窗口。
3. 点击活动栏中的 **VSRead · 青菜阅读** 书本图标，选择“打开阅读器”。
4. 在书架中导入本地电子书，或进入“在线书源”，在顶部选择书源并搜索。

也可通过命令面板执行 `VSRead: 打开阅读器`、`VSRead: 导入本地电子书`。从 VSIX 覆盖升级时，同一 IDE 用户配置中的书库和进度会保留。

阅读器右上角提供“我的书架”和“阅读设置”。设置支持点击面板外区域或按 `Esc` 关闭。

点击“专注阅读”或按 `Ctrl+Alt+H`（macOS：`⌘+⌥+H`），可收起品牌、书名、目录、工具栏与状态栏，标签页改用普通文件图标和 `notes.txt` 名称。按 `Esc`、再次使用快捷键，或悬停右上角点击恢复按钮退出；阅读位置继续自动保存。滚动模式下使用 `↑` / `↓` 章内滚动，`←` / `→` 与 `PageUp` / `PageDown` 前后阅读，在线阅读的左右键直接切章。

## 在线书源

顶部搜索下拉框提供酷我小说、零零小说、爱下书吧、下书看等网文来源，以及经致文学公开章节、Project Gutenberg 和 Standard Ebooks。选择来源后输入书名或作者，按 Enter 搜索；搜索结果加入“我的书架”，与本地书籍一起管理。

选择“聚合搜索”可同时查询多个书源，结果先到先显示，并列出各来源的进度和失败原因。相同书名、作者的结果合并展示，可选择来源后加入书架；支持调整搜索范围和停止搜索。单源搜索保留分页。

“新增书源”保留 JSON 文本和 URL 导入，兼容 VSRead 配置及部分阅读（Legado）声明式 HTML / JSON 规则。支持 CSS 选择器、简单 JSON 路径与网址模板，不执行书源 JavaScript，不处理登录、验证码或 XPath。网站可用性和章节完整性取决于来源；进入页面不会自动请求书源网站。

配置格式、兼容范围和示例见 [书源配置](docs/BOOK_SOURCES.md)。

在线阅读器提供“缓存全本”、自动预加载下一章、一键换源与“导出 TXT”。全本缓存显示已缓存章数、失败数和下载进度，支持取消与继续，跳过已有缓存并在关闭标签后继续后台运行；每本 100 MB、总计 200 MB 的缓存上限仍适用。书架顶部可对在线书籍批量检查更新并标注新章数量；“在线书源”页提供声明式正文净化规则，支持纯文本与正则替换，仅影响展示与导出，不修改原始缓存。

书源访问失败时，可点击错误提示中的“查看日志”，或执行 `VSRead: 打开诊断日志`。日志仅保存在 IDE 分配的本地日志目录，记录来源、请求阶段、状态与耗时，不记录搜索内容、章节正文或凭据。当前文件与两份轮转文件各最多约 512 KB。

## 版本更新

点击“检查更新”，发现新版本后选择“一键更新”，安装完成再点击“重载窗口”生效。下载阶段可取消，也可通过“查看发布页”下载 VSIX 手动安装；扩展不会在后台静默升级。

**0.1.8 及更早版本需先手动覆盖安装最新版本，之后即可使用一键更新。** 私有仓库的令牌配置与更新校验说明见 [版本更新](docs/UPDATES.md)。

## 数据与限制

数据存放于 IDE 分配给 `vsread-local.vsread` 的全局存储目录。不同 IDE 和用户配置的书库相互独立；备份时应复制整个存储目录。

- TXT 单文件上限 100 MB；EPUB / PDF 上限 256 MB。
- EPUB 进度百分比为近似值，位置恢复以 CFI 为准。
- PDF 保留原稿固定排版，支持深色反色与暖纸护眼滤镜；扫描件支持显示，暂不提供 OCR。
- 暂不支持 DRM 电子书、密码保护 PDF、MOBI / AZW3。
- 书签、高亮、评论和笔记管理仍在后续计划中。

## 开发

环境要求：Node.js 22.13+、VS Code API 1.85+。

```sh
npm ci
npm run check
npm run test:browser
```

在 IDE 中按 `F5` 启动扩展调试。常用命令：

| 命令 | 用途 |
| --- | --- |
| `npm run build` | 构建 Extension Host、TXT Worker 与 Webview |
| `npm run watch` | 监听源码并重新构建 |
| `npm run typecheck` | TypeScript 检查 |
| `npm test` | 运行底层测试，需先构建 |
| `npm run package` | 构建检查并生成 VSIX |

启动回归加载实际构建的 Extension Host，并模拟 VS Code API；浏览器回归模拟 Host 消息。实际 IDE 验收步骤见 [手动验收清单](docs/MANUAL_TEST.md)。变更记录见 [CHANGELOG](CHANGELOG.md)。
