# VSRead

在 CodeBuddy / Visual Studio Code 中离线阅读本地 EPUB、TXT 和 PDF。无需账号，书籍与阅读进度保存在当前设备。

当前版本为 **0.1.2 手动验收版**，已实现 P0 阅读闭环、基础书架、活动栏入口和可自定义的阅读外观。CodeBuddy 的最终兼容性和完整 IDE 重启恢复仍需按下方清单手动验证。

## 安装与打开

1. 在 IDE 扩展页面的 `…` 菜单选择“从 VSIX 安装…”（Install from VSIX）。
2. 选择项目根目录的 `vsread-0.1.2.vsix`，按 IDE 提示重载。已安装 0.1.0 / 0.1.1 时直接覆盖安装即可，无需卸载；在同一 IDE 和用户配置文件中，原有书架与进度会保留。
3. 点击左侧活动栏的 **VSRead 书本图标**，在侧栏选择“打开阅读器”或“导入本地电子书”。侧栏标题栏也提供书本和 `+` 按钮。
4. 阅读器会在编辑器标签页打开。点击“导入书籍”，选择本地 `.txt`、`.epub` 或 `.pdf`。

原命令入口仍可使用：按 `Ctrl+Shift+P`，执行 **VSRead: 打开阅读器** 或 **VSRead: 导入本地电子书**；也可以在资源管理器中右键电子书导入。

没有看到书本图标时，先执行 **Developer: Reload Window**（开发人员：重新加载窗口），再检查活动栏的 `…` 溢出菜单；也可右键活动栏，勾选 **VSRead**。不同 IDE 的活动栏位置可能被自定义，VSRead 图标会随活动栏一起显示。

首次使用建议先各导入一本体积较小、无密码且无 DRM 的书。完整检查步骤见 [手动验收清单](docs/MANUAL_TEST.md)。

## 已实现

| 格式 | 阅读能力 | 进度定位 |
| --- | --- | --- |
| TXT | 自动识别 UTF-8、GBK / GB18030、带 BOM 的 UTF-16；可手选编码；识别常见中文和英文章节标题；长章节分块；目录跳转、滚动和视口翻页 | 规范化正文的 UTF-16 字符偏移 |
| EPUB | epub.js；目录、内部图片与 CSS；书名、作者和封面提取；章节内滚动或分页；目录跳转 | EPUB CFI |
| PDF | PDF.js；单页按需渲染、缩放、翻页；内置目录（没有目录时列出页码）；文字选择和文字搜索；扫描件显示 | 页码及页内滚动比例 |

通用能力：

- 原生活动栏书本图标与侧栏入口，可直接打开阅读器、导入本地电子书。
- 基础书架、书籍切换、阅读进度显示、移除书籍；书架与阅读状态栏中的进度百分比统一保留两位小数。
- 默认跟随 IDE，也可选择浅色、深色或自定义背景与文字颜色；TXT / EPUB 可调整字号、行距和字体，PDF 可调整缩放。
- 进度与偏好自动保存；重新打开阅读器时尝试恢复最后一本书和位置。
- 内容哈希去重；导入后保留一份本地副本，移动原文件不影响副本阅读。
- 阅读器内可使用上一页 / 下一页按钮；`PageUp` / `PageDown` 和左右方向键也可翻页。

## 阅读外观与字号

点击阅读器右上角的 **阅读设置**。默认外观为“跟随 IDE”，会使用 IDE 的编辑器背景与文字颜色；也可选择浅色、深色，或自定义背景和文字颜色。自定义颜色会应用到书架、阅读器界面以及 TXT / EPUB 正文，设置会自动保存。点击设置面板外的区域（包括 EPUB 正文）或按 `Esc` 可关闭面板；在面板内调节滑块、数字和颜色时不会自动关闭。

TXT / EPUB 字号范围为 **12–40 px**，可拖动滑块或输入数字，同时支持行距和字体选择。PDF 保留固定页面排版，通过缩放改变显示大小；其页面纸色和文档内容保留原稿，背景设置作用于界面与页面周围的阅读区域。

PDF 搜索按页面显示匹配摘要和跳转入口，最多返回 100 个页面。

## PDF 加载与翻页

PDF 现在按阅读所需的文件区间读取，先显示当前页，再补充书名、作者和目录。返回书架后很快重新打开同一本 PDF，可复用已解析的文档和 Worker；近期访问过的页面也可复用画布，减少重复读取与绘制。缓存有数量、体积和闲置时间限制，只在当前阅读器中短时保留，关闭 VSRead 标签页或 IDE 后会释放。

首次打开和复杂扫描件仍受文件结构、图片解码及页面绘制复杂度影响，不能保证所有文件都以相同速度打开。阅读进度仍独立写入本地存储，缓存释放不影响位置恢复。

## 当前边界

- TXT 单文件上限 100 MB，EPUB / PDF 上限 256 MB。超长 TXT 章节按约 12,000 字符拆块，目录中显示“续”条目；继续阅读下一块时使用“下一页”。
- 手选 TXT 编码会重新解析并重置这本书的阅读位置；没有章节标题的 TXT 按正文分块。暂不支持手动划分章节。
- EPUB 阅读进度百分比是近似值，位置恢复以 CFI 为准。DRM 保护的 EPUB 和加密 PDF 暂不支持。
- 暂未实现书签、高亮、段落评论、章节评论、笔记管理、TXT / EPUB 全文搜索、OCR、MOBI / AZW3、同步和笔记导出。
- 正常关闭前请看到底部“进度已保存”。突然断电、强杀进程或磁盘写入失败时，最后一次尚未落盘的位置可能无法恢复。
- 声明使用标准 VS Code API（最低 API 版本 1.85）；不同 IDE 内嵌浏览器版本的兼容性仍以实测为准。

## 数据与隐私

运行时无需后端、CDN、云账号或在线书源；PDF Worker、CMap、字体与 WASM 资源随扩展打包。书籍字节通过 Extension Host 消息分块传入，不依赖 Webview 直接读取任意本地文件。EPUB 中的脚本和主动内容会被禁用。

数据保存在 IDE 为 `vsread-local.vsread` 分配的扩展全局存储目录：

```text
vsread-local.vsread/
├── library.json          # 书架、偏好、每本书的进度和最后打开的书
├── library.backup.json   # 上一份有效索引备份
└── books/
    └── <内容哈希>/
        ├── book.txt / book.epub / book.pdf
        └── text-<编码>/  # TXT 索引与正文分块
```

不同 IDE、用户配置文件或便携模式的数据目录可能不同，书架不会自动跨 IDE 共享。备份时应复制整个 `vsread-local.vsread` 目录。书架中的“移除”会删除扩展保存的副本及进度，保留最初选择的原文件。

## 本地开发

推荐使用 Node.js 22.13+，并使用项目的 `package-lock.json` 安装依赖：

```powershell
npm ci
npm run check
```

在 VS Code / CodeBuddy 打开本目录，按 `F5` 启动“运行 VSRead”调试配置。构建和打包命令：

```powershell
npm run build          # Extension Host、TXT Worker 与 Webview
npm run typecheck      # TypeScript 检查
npm test               # 编码、分块、存储与进度写入测试；需先构建
npm run test:browser   # 独立浏览器中的三格式阅读回归
node scripts/licenses.mjs
npm run package        # 输出 vsread-0.1.2.vsix
```

浏览器回归使用模拟 Extension Host，不能替代 CodeBuddy / VS Code 真机验收。Windows 优先使用本机 Edge；其他环境需要安装 Playwright Chromium。项目保留了独立测试 profile 的 IDE 自动化脚本，但当前交付以手动验收为准，不会在打包时自动启动 IDE。

本版性能回归包含两项可复现检查：4,195,926 字节的自制 PDF 首屏读取 525,910 字节（约 12.53%）即可正常显示；小型 PDF 在同一 Webview 内返回书架再打开时，没有新增书籍数据 RPC。这些是测试材料的传输量与复用验证，不代表所有实际 PDF 的加载耗时或固定加速倍数。

## 模块结构

```text
src/extension/         命令、导入、书库、持久化、Webview 通信与 TXT Worker
src/shared/            跨宿主与界面的数据模型、校验
src/webview/           React 界面、书架、目录、偏好与进度写入
src/webview/readers/   TXT / EPUB / PDF 适配器及统一接口
test/                  底层测试、样例生成与浏览器回归
```

插件主体与阅读适配器分离，后续可以增加评论锚点、笔记存储或替换宿主。当前项目没有 Spring Boot 或其他后端服务。
